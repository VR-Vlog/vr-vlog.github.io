Preserves the existing VCC/ALCOM registration at https://vr-vlog.github.io/VR-Vlog-lilToon-Exporter/index.json. The repository identity and published package IDs, versions, ZIP filenames and SHA-256 values are retained. Browser HTML points to https://vrvlog.fun/exporter/.

The approved Exporter Build VPM Listing flow will synchronize only the legacy exporter JSON prefix using its dedicated VPM_ORG_MIRROR_TOKEN. Preserve the old prefix even if other organization pages are added. Never create the old-named source repository; GitHub old source and release URL redirects must remain.
